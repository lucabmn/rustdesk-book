# Task for researcher

Recherchiere anhand von Primärquellen (offizielle RustDesk-Dokumentation, offizielle RustDesk-/RustDesk-Server-Pro-Repositories und Quellcode, offizielle API-Dokumentation) eine technisch belastbare Möglichkeit, RustDesk-Clients automatisiert auf Linux, Windows und macOS auszurollen und dabei ein Gerät automatisch in dieser Anwendung „rustdesk-book“ zu registrieren. Zielbild: Im Portal wird ein Installationsskript mit einmalig gültigem Device-/Enrollment-Token oder optional statischem Token für GPO/MDM bereitgestellt; nach Installation sollen Name, RustDesk-ID, Kennwort und relevante Metadaten sicher im rustdesk-book landen. Kläre insbesondere: unbeaufsichtigte Installation je OS; Konfiguration von ID/Relay/API-Server und Server-Key; ob RustDesk selbst Enrollment-/Device-Tokens oder eine Management-API anbietet (OSS vs Pro); wie ID und permanentes Kennwort gesetzt/ausgelesen werden können; verfügbare CLI-Parameter; macOS-Berechtigungsgrenzen (TCC/PPPC); sichere Token- und Secret-Architektur; realistischer End-to-End-Flow und Alternativen. Unterscheide sicher belegte Fakten, Quellcodebefunde und eigene Designempfehlungen. Zitiere jede wesentliche Aussage mit direktem Link auf die Primärquelle und nenne Datum/Version/Commit, soweit möglich. Schreibe das Ergebnis auf Deutsch als einzelne Markdown-Datei im Repo unter docs/research/rustdesk-client-enrollment.md. Keine sonstigen Dateien ändern. Antworte danach mit einer knappen Zusammenfassung der wichtigsten Erkenntnisse und dem Dateipfad.
