# Task for scout

Analysiere den aktuellen Stand dieses Repositories für die Implementierung eines RustDesk-OSS-Client-Enrollments. Anforderungen: Admin/Nutzer kann im Portal einen einmalig nutzbaren Token (genau 1 Device) oder permanenten Token erstellen; optional soll RustDesk installiert werden, falls es nicht gefunden wird; erzeugtes OS-spezifisches Deployment-Skript muss RustDesk unabhängig vom Installationspfad finden, ggf. installieren, Server-Konfiguration setzen, starkes permanentes Passwort setzen, ID auslesen und das Gerät in genau dieser rustdesk-book-Instanz registrieren. Kein RustDesk Pro. Untersuche Routing/Auth-Konventionen, DB-Schema/Migrationen, UI-Struktur, i18n, Tests und bestehende uncommittete Änderungen. Liefere einen konkreten, kompakten Implementierungsplan mit betroffenen Dateien, Risiken und sinnvollen Modul-Seams. Nur lesen, nichts ändern.
